`echo`, a neutral C library a language implementation's host tests load as a host service, built beside the core so those tests need no other repository and are pinned with the core they test. It is a test target only, linked into nothing the core ships. Its bytes functions answer the input, a refusal, bytes that are not UTF-8, the address they were handed and a count of the bodies released, so a binding can prove it lends or copies its input and releases every body; its definitions answer a struct of operations, structs at and one byte below the smallest size a host loads, and NULL, so a host can prove where it loads one and where it refuses. What a host must do with a library of either kind is in [the contract's `host` module](../../../contract/host.md).
